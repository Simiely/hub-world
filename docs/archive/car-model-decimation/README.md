# 汽车高精度模型减面：逆向优化工作流

> 近景查看的镜面烤漆车，纯自动减面无法达到品质要求、不能直接出货；自动减面最多只能打底，棱线和高光区必须由人工接管。本仓库是一个**交互式技术文档**，讲解「先做 10 万面卡位 → 收缩包裹锚定 → Catmull-Clark 细分到 30 万 → 可选弱包裹微调」的逆向优化工作流。

🌐 **在线预览**：https://simiely.github.io/car-model-decimation/

## 项目简介

针对「30 万与 10 万都需手动精修、总面数固定」的约束，逆向流程把最耗脑力的**三维定位外包给计算机**，让修形退化为**二维整理**——相比「先拓 30 万母版再删线」，更快、更可控。

- **核心主角**：新工作流（怎么做）+ 为什么高效（为什么快）
- **辅助内容交互化**：打比方、对比表、文献来源全部用折叠 / 浮层 / 切换呈现，不占主线
- **时间收益**：约 **50～55%** 的时间节省（⚠️ 示意性估算，非行业基准）

## 页面结构

| 区块 | 内容 | 交互 |
|---|---|---|
| Hero | 核心论点一句话 + 效率指标卡 | 数字带免责标注 |
| 工作流 | 三阶段步骤卡 + 修改器堆栈图 | 点击展开/收起 |
| 为什么高效 | 效率驱动因素 A~E + 对照 F + 为何不能自动 G | 每条可展开「打比方」 |
| 效率对比 | 传统流程 vs 逆向流程 | 可切换「并排 / 仅看逆向」 |
| 适用场景 | 材质 / 查看距离 / 返工率 决策表 | 静态 |
| 参考文献 | 验证来源 `[1]~[10]` | 正文 `[n]` 点击浮层 + 文末折叠清单 |

## 使用方法

1. **打开**：双击 `index.html`（或拖入浏览器）即可，**零依赖、无需服务器**。
2. **看工作流**：点击「阶段一 / 二 / 三」卡片展开每步细节，内嵌修改器堆栈图。
3. **看论证**：展开「打比方」折叠块理解比喻；点击正文上标 `[n]` 弹出对应文献来源。
4. **比效率**：对比表右上角切换「并排 / 仅看逆向」视图。
5. **查来源**：文末「验证来源与参考文献」章节可整体折叠/展开。
