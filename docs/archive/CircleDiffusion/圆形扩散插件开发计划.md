# AE 圆形扩散插件 — 开发计划（v2 优化版）

> 基于三份参考开发文档的实战经验 + 架构审查优化

## 一、需求分析

### 1.1 核心效果

| 编号 | 效果模式 | 描述 |
|------|---------|------|
| M1 | 纯线扩散 | 圆形线（ring）从中心向外扩散，多个同心圆环 |
| M2 | 纯粒子扩散 | 粒子从中心/圆环位置向外径向扩散 |
| M3 | 线+粒子组合 | 扩散的圆环线 + 内圈粒子，粒子密度从线向外递减 |

### 1.2 用户明确要求的控制参数

| 参数 | 说明 |
|------|------|
| 扩散速度 | 圆环半径扩大的速率 |
| 粒子密度 | 粒子数量/分布密度 |
| 线粗细 | 圆环描边宽度（stroke width） |
| 粒子集合长度 | 粒子分布离线的最大距离（带宽） |
| 粒子密度渐变 | 靠近线最密，远离线稀疏（密度衰减曲线） |

### 1.3 建议补充的扩展控制参数

| 参数 | 说明 | 理由 |
|------|------|------|
| 圆环数量 | 同时扩散的同心圆环数 | 丰富层次感 |
| 扩散方向 | 从内向外 / 从外向内 | 双向表现力 |
| 生成方式 | Shape Layer / Radio Waves | 精细控制 vs 极简一键 |
| 粒子尺寸范围 | 最小/最大粒子大小 | 自然随机感 |
| 粒子颜色 | 色相/饱和度/亮度 (HSL) | 色相偏移更直观 |
| 线颜色 | 圆环颜色 (HSL) | 与粒子统一色彩空间 |
| 线透明度 | 圆环透明度 + 淡入淡出 | 柔和过渡 |
| 粒子透明度 | 粒子淡入淡出 + 闪烁 | 动态质感 |
| 粒子生命周期 | 粒子存在时长 | 控制轨迹长度 |
| 随机种子 | 整体复位随机分布 | 可复现性 |
| 扩散中心位置 | X/Y 坐标（合成尺寸百分比） | 定位灵活 + 分辨率无关 |
| 起始/结束半径 | 扩散范围边界（合成尺寸百分比） | 控制扩散区间 |
| 线扩散间隔 | 多圆环之间的间距 | 层次节奏 |
| 运动模糊 | 粒子/线的运动模糊开关 | 动态质感 |
| 粒子形状 | 圆形/方形/星形 | 风格多样 |
| 扩散缓动曲线 | 线性/缓入/缓出 | 运动节奏 |
| 外发光强度 | Glow 效果开关和强度 | 提升视觉质感 |
| 拖尾效果 | Echo 效果实现粒子拖尾 | 减少图层数仍保持丰富感 |

## 二、技术选型

### 2.1 方案对比

| 方案 | 技术栈 | 优点 | 缺点 |
|------|--------|------|------|
| **ExtendScript ScriptUI** | JavaScript ES3 + AE API | ✅ 开发周期短 ✅ 部署简单 ✅ 参考项目完备 | ❌ UI 简陋 ❌ 不能实时预览 |
| CEP Panel | HTML/CSS/JS + ExtendScript | ✅ UI 美观 ✅ 可停靠 | ❌ 调试复杂 ❌ 需配置 manifest |
| C++ AEGP 效果插件 | C++ + AE SDK | ✅ 性能最优 ✅ GPU 加速 | ❌ 开发周期长 ❌ 需编译工具链 |

### 2.2 推荐方案：ExtendScript ScriptUI Panel

**理由：**
1. 三个参考项目已验证此方案在 AE 2026 中文版可行
2. 核心是"生成图层+挂表达式"，不需要像素级渲染
3. 单文件部署，双击运行
4. AE 内置的 Shape Layer API 和表达式引擎足够覆盖所有需求

**创建圆环的 ExtendScript 关键代码：**

```javascript
// 1 个 Shape Layer，N 个 Shape Group
var shapeLayer = comp.layers.addShape();
shapeLayer.name = "扩散_线";
var contents = shapeLayer.property("ADBE Root Vectors Group");

for (var i = 0; i < ringCount; i++) {
    // 每个环 = 1 个 Group
    var group = contents.addProperty("ADBE Vector Group");
    group.name = "Ring_" + i;
    var groupContents = group.property("ADBE Vectors Group");
    
    // Ellipse Path
    var ellipse = groupContents.addProperty("ADBE Vector Shape - Ellipse");
    var sizeProp = ellipse.property("ADBE Vector Ellipse Size");
    sizeProp.expression = ringSizeExpr(i);  // 挂半径表达式
    
    // Stroke
    var stroke = groupContents.addProperty("ADBE Vector Graphic - Stroke");
    var widthProp = stroke.property("ADBE Vector Stroke Width");
    widthProp.expression = strokeWidthExpr();
    
    // Group Transform（控制环的位置偏移）
    var transform = group.property("ADBE Vector Transform Group");
    var posProp = transform.property("ADBE Vector Position");
    posProp.expression = centerPosExpr();  // 扩散中心偏移
}
```

## 四、核心技术方案

### 4.1 线扩散实现（主方案：Shape Layer 多 Group）

**方案：1 个 Shape Layer + N 个 Shape Group，每个 Group 含 Ellipse + Stroke**

```
Shape Layer "扩散_线"          ← 永远只占 1 个图层
├── Group "Ring_0"
│   ├── Ellipse Path → Size 表达式 → 环 0 的直径
│   ├── Stroke → Width/Color 表达式
│   └── Transform → Position 表达式（中心偏移）
├── Group "Ring_1"
│   ├── Ellipse Path → Size 表达式 → 环 1 的直径
│   ├── Stroke → Width/Color 表达式
│   └── Transform → Position 表达式
└── Group "Ring_2" ...
```

**表达式（Ellipse Size 属性，2D 返回 [直径, 直径]）：**

```javascript
// buildRingSizeExpr(ringIndex)
ctrl = thisComp.layer("Ctrl_Diffusion");
startPct = ctrl.effect(10)(1);  // Start Radius(%)
endPct = ctrl.effect(11)(1);    // End Radius(%)
spacingPct = ctrl.effect(12)(1); // Ring Spacing(%)
speed = ctrl.effect(2)(1);       // Diffusion Speed
direction = ctrl.effect(3)(1);   // 0=outward, 1=inward
easing = ctrl.effect(30)(1);     // Easing Power

refSize = Math.min(thisComp.width, thisComp.height);
startPx = startPct / 100 * refSize;
spacingPx = spacingPct / 100 * refSize;

t = time - ctrl.inPoint;  // ★从播放头开始（Ctrl 层 inPoint = 当前时间）
totalDur = (endPct - startPct) / 100 * refSize / speed;
easedT = Math.pow(Math.min(t / totalDur, 1), easing) * totalDur;

baseR = startPx + spacingPx * ringIndex;  // ★ringIndex 从脚本传入
currentR = baseR + speed * easedT * (direction == 0 ? 1 : -1);
[currentR * 2, currentR * 2];  // ★Size 是直径，不是半径
```

**关键点：**
- **1 个图层管理全部圆环**，图层数从 O(N) 降到 O(1)
- `ctrl.inPoint` 对齐播放头（Ctrl 层在生成时 `startTime = comp.time`）
- Size 属性是直径 `[2R, 2R]`
- 所有距离参数用合成较短边的百分比 → **分辨率无关**

### 4.2 线扩散备选方案：Radio Waves（极简模式）

适用于不需要精确控制每环间距的快速场景：

```javascript
// 在 Solid 层上添加 Radio Waves 效果
var solid = comp.layers.addSolid([1,1,1], "扩散_RadioWave", comp.width, comp.height, 1);
var radioWaves = solid.property("ADBE Effect Parade").addProperty("ADBE Radio Waves");

// 配置核心参数（通过 matchName）
radioWaves.property("ADBE Radio Waves-0001").setValue(centerX, centerY); // Producer Point
radioWaves.property("ADBE Radio Waves-0002").expression = frequencyExpr;  // 频率 = 扩散速度
radioWaves.property("ADBE Radio Waves-0003").expression = expansionExpr;  // 扩展速度
radioWaves.property("ADBE Radio Waves-0006").setValue(lifespan);          // 生命周期
radioWaves.property("ADBE Radio Waves-0010").setValue(color);             // 颜色
```

|------|---------------------|-------------|

### 4.3 粒子扩散实现

**方案：多个小 Shape Layer + 表达式驱动 Position（径向运动）**

```javascript
// Position 表达式（关键：粒子在线的内外两侧分布）
ctrl = thisComp.layer("Ctrl_Diffusion");
startPct = ctrl.effect(10)(1);
speed = ctrl.effect(2)(1);
collectionLen = ctrl.effect(9)(1);    // 集合带宽
falloff = ctrl.effect(10)(1);         // 密度衰减指数
seed = ctrl.effect(28)(1);            // 随机种子
centerXPct = ctrl.effect(29)(1);
centerYPct = ctrl.effect(30)(1);

refSize = Math.min(thisComp.width, thisComp.height);
startPx = startPct / 100 * refSize;
cx = centerXPct / 100 * thisComp.width;
cy = centerYPct / 100 * thisComp.height;

t = time - ctrl.inPoint;
baseRadius = startPx + speed * t;

// ★种子随机：角度
seedRandom(index + seed + 2000, true);
angle = random(0, Math.PI * 2);

// ★密度衰减：幂函数将均匀随机映射到偏向 0 的分布
seedRandom(index + seed + 7000, true);
rawRandom = random();
biasedRandom = Math.pow(rawRandom, falloff);  // falloff>1 → 偏向 0

// ★内外两侧分布（-collectionLen ~ +collectionLen）
seedRandom(index + seed + 7500, true);
directionSign = random() < 0.5 ? -1 : 1;
offset = biasedRandom * collectionLen * directionSign;

currentRadius = baseRadius + offset;

x = cx + currentRadius * Math.cos(angle);
y = cy + currentRadius * Math.sin(angle);
[x, y]
```

**粒子位置分布改进对比：**

```
❌ 旧版:  offset = random(0, collectionLen)         → 粒子全在线外侧
✅ 新版:  offset = biasedRandom * collectionLen * (±1) → 粒子内外两侧，近线密集
```

### 4.4 组合模式（M3）— 核心难点：密度渐变

**方案：复用线扩散的线 + 粒子跟随线运动，粒子径向偏移用幂函数分布**

M3 组合模式中：
- 线用 4.1 的 Shape Layer 方案
- 粒子用 4.3 的表达式，但粒子基准位置跟随最外圈圆环
- **粒子和线引用同一个 Ctrl 层**，改一个滑块 → 线和粒子同时变化

**分布特征可视化：**

```
falloff = 1.0 (均匀)
  线|████████████████████████|  每个距离区间粒子数相等

falloff = 2.0 (偏向近线)  
  线|████████████████░░░░░░░░|  近线密集，远线稀疏

falloff = 4.0 (强烈聚集)
  线|████████████████████░░░░|  大部分粒子紧贴线

falloff = 0.5 (偏向远处)
  线|██░░░░░░░░░░░░░░░░░░░░░░|  反分布，远处密（用于特殊效果）
```

**粒子生命周期控制轨迹长度：**

```javascript
// Opacity 表达式
seedRandom(index + seed + 1000, true);
lifespan = random(minLife, maxLife);  // 每个粒子独立生命周期
fadeIn = 0.3;  // Fade In Duration
fadeOut = 0.8; // Fade Out Duration

t = time - ctrl.inPoint;
opacity = linear(t, 0, fadeIn, 0, maxOpacity) * linear(t, lifespan - fadeOut, lifespan, maxOpacity, 0);
opacity
```

### 4.5 播放头对齐机制

**问题**：用户播放头在 5 秒处点"生成"，动画应该从 5 秒开始扩散。

**实现**（参考歌词动画器方案）：

```javascript
// generateRings() / generateParticles() 中
var startTime = comp.time;  // ★读播放头位置

// Controller Null 层：inPoint = startTime
var ctrl = comp.layers.addNull();
ctrl.startTime = startTime;
ctrl.name = "Ctrl_Diffusion";

// 所有表达式统一引用 ctrl.inPoint
// t = time - ctrl.inPoint  → 动画相对起点
```

### 4.6 图层清理机制

```javascript
// removeGeneratedLayers(prefix)
function removeGeneratedLayers(prefix) {
    var comp = getActiveComp();
    if (!comp) return;
    
    // 从后往前删（避免索引变化）
    for (var i = comp.numLayers; i >= 1; i--) {
        var layer = comp.layer(i);
        if (layer.name.indexOf(prefix) === 0) {
            layer.remove();
        }
    }
}

// 所有生成图层统一前缀命名
// 线: "扩散_线"      粒子: "扩散_粒子_N"      控制器: "Ctrl_Diffusion"
// 一键清理: removeGeneratedLayers("扩散_"); removeGeneratedLayers("Ctrl_Diffusion");
```

### 4.7 色彩空间统一：HSL

```javascript
// HSL → RGB 转换（表达式内嵌，无外部依赖）
function hslToRgb(h, s, l) {
    h = h % 360;
    s = s / 100;
    l = l / 100;
    var c = (1 - Math.abs(2 * l - 1)) * s;
    var x = c * (1 - Math.abs((h / 60) % 2 - 1));
    var m = l - c / 2;
    var r, g, b;
    if (h < 60) { r = c; g = x; b = 0; }
    else if (h < 120) { r = x; g = c; b = 0; }
    else if (h < 180) { r = 0; g = c; b = x; }
    else if (h < 240) { r = 0; g = x; b = c; }
    else if (h < 300) { r = x; g = 0; b = c; }
    else { r = c; g = 0; b = x; }
    return [r + m, g + m, b + m, 1];
}
```

线和粒子共用这套 HSL → RGBA 转换，色相滑块独立可调。

### 4.8 seedRandom Offset 分配表

| Offset | 用途 | 使用表达式 |
|--------|------|-----------|
| 1000 | 粒子生命周期 | Position, Opacity |
| 2000 | 粒子角度 | Position |
| 3000 | 粒子径向偏移（原始随机） | Position |
| 4000 | 粒子大小 | Scale |
| 5000 | 粒子颜色(H) | Color |
| 6000 | 粒子颜色(S) | Color |
| 7000 | 密度衰减偏移（幂函数输入） | Position |
| 7500 | 方向符号 (±1) | Position |
| 8000 | 时间偏移（闪烁相位） | Opacity |
| 9000 | 透明度随机 | Opacity |

### 4.9 表达式跨语言兼容

根据 AudioScale 和 starry-sky 的教训：

```javascript
// ❌ 绝对不能用：表达式里写中文名
effect("扩散速度")(1)

// ✅ 控制器层的 effect 用索引（已知顺序不会变）
// 因为 Ctrl 层的效果是脚本按固定顺序添加的
effect(2)(1)   // 第 2 个效果 = Diffusion Speed

// ✅ 图层引用：用 matchName
thisComp.layer("Ctrl_Diffusion")

// ✅ 属性访问：用 matchName + fallback
prop.property("ADBE Vector Ellipse Size")
```

**唯一例外**：`fx()` 帮助函数可用于非控制器的效果引用（如 Glow、Echo）。

### 4.10 拖尾效果（用更少粒子实现丰富视觉）

```javascript
// 给粒子图层 Pre-comp 后添加 Echo 效果
// 替代方案：直接在粒子图层组上添加 Adjustment Layer + Echo
function addEchoEffect(targetLayer, frames, intensity) {
    var echo = targetLayer.property("ADBE Effect Parade").addProperty("ADBE Echo");
    echo.property("ADBE Echo-0001").setValue(frames);      // Echo Time (frames)
    echo.property("ADBE Echo-0002").setValue(1);            // Number of Echoes
    echo.property("ADBE Echo-0005").setValue(intensity);    // Decay
}
```

**效果**：80 个粒子 + Echo=3 帧 = 视觉效果接近 240 个粒子，但图层数只有 80。

## 十、技术风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 大量粒子图层性能下降 | 中 | 粒子上限 300 + Echo 拖尾替代方案 + Shape Layer 本身轻量 |
| AE 2026 Shape Layer API 变化 | 中 | 三份参考文档已验证 matchName 稳定 |
| Single Shape Layer N Groups 兼容性 | 低 | Shape Group API 自 CS6 起稳定，跨版本一致 |
| Radio Waves matchName 变化 | 低 | 提供 Shape Layer fallback，并非唯一方案 |
| 表达式复杂度 → 评估慢 | 低 | seedRandom(timeless=true) 缓存 + 避免嵌套 if |
| ScriptUI 面板布局异常 | 中 | 固定标签宽度 + fill 对齐 + layout(true) 强制重排 |
| `comp.time` 为 0 时生成 | 低 | 检测并给出提示 |
| 无合成时点击生成 | 低 | ensureComp() 前置检查，自动创建或提示 |
