# 唱歌片段检测 — 三方技术辩论共识

> 本文是 `singing-segment-detector` skill 的方法论来源。完整五轮辩论见 `/workspace/singing_timestamp_debate.md`（若已附带）。此处压缩为**可直接落地的架构、阈值逻辑与验收口径**。

## 1. 问题定义

输入：长视频/音频，混合三类片段：
- **谈话**（人声说话，碎片化、无颤音、音高跳变）
- **背景音 + 屏幕文字**（无人声，BGM/和弦/音效）
- **唱歌**（人声歌唱，持续音高、带颤音、有旋律移动）

输出：**所有唱歌片段的起止时间戳（JSON + SRT，带置信度）**。

硬标准：**稳定好用 + 性能好**。

## 2. 三套候选方案（辩论演变）

| 轮次 | 提出人 | 方案 | 主要批评 |
|------|--------|------|----------|
| R1 | A（稳哥/实用） | 纯 librosa 信号特征（RMS/ZCR/自相关 f0/过零率），规则阈值判唱 | 说话 vs 唱歌特征重叠，纯规则召回/精确双低 |
| R2 | B（模型姐） | Demucs 抽人声干声 + 预训练 singing/voice 分类模型，端到端 | 重依赖、慢、需标注数据、跨语种/风格泛化存疑 |
| R3 | C（老周/工程） | **混合 + 多模态兜底**：抽人声 → 规则快通道(小模型补漏) → 灰区多模态(看口型/歌词/能量包络) → 场景分级 | 多模态成本高，应只在灰区启用 |
| R4 | A/B 深化 | 性能边界、数据漂移、可复现、唱中夹说切分 | 需 CI 回归 + 场景分级表 |
| R5 | 三方收敛 | 最终工程验收清单 + 分级策略 | — 达成 |

## 3. 收敛共识架构

```
抽人声
  └─► 规则快通道（fast 档，零重依赖，纯 numpy+ffmpeg）
        ├─ voiced 时间连续性  ← 主区分信号（说话碎片化 vs 唱歌持续）
        ├─ 音高连续性 / voiced 占比（辅助）
        └─ 过零率过高压分（念稿清辅音）
  └─► （可选）小模型补漏：规则灰区用轻量分类器二次判定
  └─► 灰区多模态兜底：口型/歌词/能量包络（仅在规则不确定时启用）
  └─► 场景分级策略：fast 预览 / accurate 交付
        └─► 后处理：中值滤波 → 最短时长 → 间隙合并(唱中夹说双阈值) → 边界内收
```

## 4. 关键调试结论（决定 fast 档判据）

- **「颤音」不可靠作 fast 主判据**：纯自相关 f0 估计的帧抖动量级 ≈ 真实唱歌颤音量级，且随基频高低变化（低频说话的算法抖动会被放大成"假颤音"）。→ fast 档改用 **voiced 时间连续性** 为主信号；真正的颤音/人声特性交给 accurate 档（人声分离 + 模型）。
- **f0 置信度公式**：`conf = 基频峰 / 零延迟自相关(=总能量)`，有界 [0,1]，纯周期音≈0.5，噪声≈0；避免用"有符号自相关均值"（正负抵消→负值→截 0 导致全 0）。
- **f0 取最低频率显著局部峰**：避免把谐波误判为基频（八度错误）。
- **帧间稳定**：八度纠错 + 一致性约束（只允许 ±2.5 半音小抖动与八度跳变通过，谐波锁定引起的非八度跳变继承前一帧），抑制把抖动当颤音。

## 5. 后处理要点

- **中值滤波**（k=3）去单帧毛刺。
- **最短时长过滤**（默认 2.5s）：丢掉短促清唱/哼唧。
- **间隙合并 + 唱中夹说双阈值**：
  - 段间间隙 < `merge_gap`(1.0s)：纯静音 → 合并；有声 → 看音高是否剧烈跳动（>400 cents 均值 → 判定转说话，切分；否则视为换气合并）。
  - 停顿 < `breathe_gap`(0.8s) 且音高连续 → 换气合并。
- **边界内收**（`trim_thr`=0.6）：段两端若 score 仅略高于阈值（过渡帧），向内裁掉收紧时间戳，前提裁后段长仍 ≥ `min_duration`。

## 6. 工程验收口径（Acceptance）

| 指标 | 目标 |
|------|------|
| 召回 recall | ≥ 95%（唱歌段不漏） |
| 精确 precision | ≥ 92%（报出的段主要是真唱歌，边界 ±0.5s 内可接受） |
| 速度（每 1h 视频，CPU） | fast < 3min；accurate < 15min |
| 可复现 | 相同输入 + 相同参数 → 相同输出（无随机种子依赖） |
| CI 回归 | `synthesize_test.py` 三段样本稳定检出唱歌、排除说话与 BGM |

## 7. 场景分级表

| 场景 | 推荐档 | 说明 |
|------|--------|------|
| 快速预览 / 批量粗定位 | fast | 零重依赖，纯 CPU，秒级 |
| 无 GPU / 无模型环境 | fast | 降级也能跑 |
| 交付级时间戳 / 边界敏感 | accurate | 人声分离后判唱，边界更准 |
| 多人合唱 / 和声 / 说唱 / 高噪声（OOD） | accurate + 多模态兜底 | 纯规则鲁棒性有限，灰区用多模态 |

## 8. 已知限制 / 盲点

- fast 档是粗筛，边界 ±0.5s 滑窗溢出，交付级请用 accurate。
- 多人/OOD/说唱/极高噪声：纯规则召回下降，需 accurate + 多模态。
- 数据漂移：长期需 CI 回归 + 周期性用新样本重测阈值。
