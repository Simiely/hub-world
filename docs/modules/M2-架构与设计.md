# M2 架构与设计

> 各项目的架构设计、模块划分、技术选型与数据流。改代码前先看这里。

## 🐍 Python 后端

### obsidian-agent

> 📌 来源:`obsidian-agent` · docs/02-架构设计.md

**技术栈**:FastAPI + Vue3 + SQLite FTS5/Meilisearch + Pydantic AI + Docker

```
app/
├── main.py          # 应用入口
├── config.py        # pydantic-settings 配置加载
├── core/            # 领域核心(不依赖 Web 框架)
│   ├── vault.py     #   vault 访问:树/读写/监听/忽略规则
│   ├── markdown.py  #   md 解析:frontmatter/wikilink/结构
│   ├── indexer/     #   索引模块(可插拔:FTS5 默认 / Meilisearch 可选)
│   ├── search.py    #   检索服务(高亮/分页/定位)
│   └── backup.py    #   快照备份/定时/保留/恢复
├── agent/           # AI Agent(Pydantic AI)
│   ├── llm/         #   模型配置层(DeepSeek/OpenAI/Kimi/Ollama)
│   ├── tools/       #   类型化工具
│   ├── loop.py      #   会话/HITL 批准
│   └── safety.py    #   编辑安全:备份/diff/路径白名单
└── api/             # REST API 路由
```

**核心设计原则**:
1. 不破坏你的库(编辑保留原始 md 语法,写文件前自动备份 + diff 预览)
2. 可插拔(索引引擎、LLM 提供商走抽象接口)
3. 模块化(核心层不依赖 Web 框架)
4. 中文友好(全文检索内置中文分词)

### homekeeper(拾光集)

> 📌 来源:`homekeeper` · docs/05-开发指南.md

**技术栈**:FastAPI + SQLite + 原生 HTML/CSS/JS + SQLAlchemy 2.x + Pydantic v2 + JWT

模块化结构,核心能力:
- 账号:管理员创建用户 / JWT 登录 / 数据隔离
- 物品:名称/数量/状态/保质期/图片附件
- 位置:可视化层级树(房间>区域>容器)
- 通知:Web Push 过期提醒
- 图片:上传 → WebP 压缩 → 缩略图

## 📱 微信小程序

### collab-plan-miniprogram(私有)

> 📌 来源:`collab-plan-miniprogram` · docs/02-architecture.md

**技术栈**:微信云开发 CloudBase + 原生小程序 + 零依赖 Node 单测

核心设计:
- 自建账号密码登录(非微信授权,账号可跨微信复用,Token 30 天滑窗续期)
- 同步引擎:服务器时间戳水位线 + 复合游标分页 + 本地库 + 离线队列,**先 push 后 pull**
- 提醒系统:订阅消息 + 自建额度池 + 定时触发器
- 测试:内存 Mock 严格复刻真实 wx-server-sdk

### miniprogram-item-expiry

> 📌 来源:`miniprogram-item-expiry` · README.md

```
[小程序] <-> [云开发数据库 items](主数据源)
              | 数据库触发器
              v
      [云函数 syncToDocs] -> [腾讯文档智能表]
              ^
      [云函数 syncFromDocs](定时/手动) <- [腾讯文档智能表]
```

设计取舍:云开发做主数据源规避备案域名门槛;腾讯文档作为"家人协同视图"。

## 🎬 设计插件 / 工具

### hub-world

> 📌 来源:`hub-world` · DEVELOPMENT.md

单文件 SPA(index.html + projects.json 数据分离):

```
projects.json ──fetch──▶ DOMContentLoaded ──▶ initFloatingCards()
                                                  renderCatalog()
```

- fetch 失败自动用 `FALLBACK_PROJECTS` 兜底
- 深/浅色主题、卡片网格 + 分类筛选(web / tool / design)

### resources(私有)· 软件资源库

> 📌 来源:`resources` · README.md

**数据/展示分离**架构:

```
软件分类.md ──parse──▶ 结构化 JSON ──embed──▶ software-catalog.html
                          ▲                     (静态外壳 + 前端渲染器)
                  build_catalog.py
```

更新 md 后重跑脚本只替换 HTML 数据块,外壳不变、diff 清晰。
