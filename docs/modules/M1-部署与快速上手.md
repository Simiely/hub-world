## 🐍 Python 后端项目

### homekeeper(拾光集)· 家居物品管理

> 📌 来源:`homekeeper` · README.md / docs/04-部署指南.md

**方式 A:拉取预构建镜像(推荐)**

```bash
docker run -d --name homekeeper \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  -e SECRET_KEY="改为随机字符串" \
  ghcr.io/simiely/homekeeper:latest
```

**方式 B:源码构建**

```bash
git clone https://github.com/Simiely/homekeeper.git
cd homekeeper
cp .env.example .env        # 修改 SECRET_KEY 为随机长字符串
docker compose up -d --build
```

- 访问:`http://<服务器IP>:8000`(默认管理员 `admin / Mm123456.`)
- 交互式 API 文档:`http://<服务器IP>:8000/docs`
- 数据落盘:`./data/homekeeper.db`

### obsidian-agent · Obsidian AI 助手

> 📌 来源:`obsidian-agent` · README.md / docs/03-快速开始.md

```bash
git clone https://github.com/Simiely/obsidian-agent.git
cd obsidian-agent
cp .env.example .env        # 配置 VAULT_PATH、LLM_PROVIDER、LLM_API_KEY
docker compose up -d
# 浏览器访问 http://localhost:8080
```

支持 LLM:DeepSeek / OpenAI / Kimi / 本地 Ollama。

### learning-platform · 幼儿闪卡平台

> 📌 来源:`learning-platform` · README.md

```bash
git clone https://github.com/Simiely/learning-platform.git
cd learning-platform
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate && python manage.py seed_sync
python manage.py runserver 0.0.0.0:8000
# 打开 http://localhost:8000
```

## 🤖 Android 项目

### android-adskip · 广告跳过

> 📌 来源:`android-adskip` · README.md

1. 从 [Releases](https://github.com/Simiely/android-adskip/releases) 下载 APK
2. 设置 → 无障碍 → AdSkip → 开启
3. 开启悬浮窗权限
4. 打开任意有广告的 App 即自动工作

### DarkMask · 夜深模式

> 📌 来源:`DarkMask` · README.md

1. 从 [Releases](https://github.com/Simiely/DarkMask/releases) 下载 `yeshen-mode-*.apk`
2. 首次安装授予悬浮窗权限、通知权限(Android 13+)
3. 后续版本可直接覆盖安装(固定签名)

## 📱 微信小程序项目

### collab-plan-miniprogram · 协作计划(私有)

> 📌 来源:`collab-plan-miniprogram` · docs/12-deploy-guide.md

```bash
npm install        # 安装依赖并自动同步 _shared → 各云函数 common/
npm test           # 跑单测(295 项断言)
npm run sync:shared
```

3. 仅本地使用不改云配置即可跑;跨设备需配置云开发环境
