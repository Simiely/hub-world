# M4-02 微信小程序开发指南

> 覆盖 collab-plan-miniprogram(私有)、potty-training-miniprogram、miniprogram-item-expiry。

## 云开发(CloudBase)项目

> 📌 来源:`collab-plan-miniprogram` docs/07-conventions.md

### 项目约定

- 前端:微信小程序原生(WXML/WXSS/JS),不用 npm 构建
- 后端:云函数 + 定时触发器,免鉴权 openid
- **共享层**:云函数间公共代码放 `_shared`,用 `npm run sync:shared` 同步到各云函数 `common/`
- **测试**:零依赖 Node 单测,`tests/mocks/wx-server-sdk` 内存 Mock 复刻真实 SDK

### 常用命令

```bash
npm install          # 安装依赖并同步 _shared
npm test             # 跑单测(295 项断言)
npm run sync:shared  # 手动同步云函数公共层
```

### 数据模型设计要点

- 主数据源选择:云开发数据库(规避备案域名门槛)
- 映射表:云库 `_id` ↔ 外部系统 `recordId`(防重复同步)
- 增量同步:时间戳水位线 + 复合游标分页 + 本地库 + 离线队列,先 push 后 pull

## 本地 + 云端双模式(potty-training-miniprogram)

> 📌 来源:`potty-training-miniprogram` · README.md / DEV.md

- `utils/store.js` 统一数据层:`USE_CLOUD` 一行切换本地 / 云端
- 本地:`wx.Storage`;云端:`wx.cloud.database`
- 大屏/iPad 适配:`resizable` + `screenWidth` 判定 + `.tablet` 类 + px 覆盖(CSS @media 在 iPad 不命中)

## 腾讯文档双向同步(miniprogram-item-expiry)

> 📌 来源:`miniprogram-item-expiry` · DEVELOPMENT.md

- 云函数:`authDocs`(OAuth 换 token)、`syncToDocs`(数据库触发器)、`syncFromDocs`(定时轮询)
- 环境变量:`TDOC_APPID` / `TDOC_SECRET` / `TDOC_FILE_ID` / `TDOC_SHEET_ID` / `TDOC_REDIRECT_URI`
- ⚠️ 腾讯文档 OAuth 回调仍需**自己备案的域名**
