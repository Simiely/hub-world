# M4-04 桌面与脚本工具开发指南

> 覆盖:C# 桌面工具(WindowTinter)、AE 插件系列、C4D/Blender 插件、MaxScript 工具。

## C# 桌面工具(WindowTinter)

> 📌 来源:`WindowTinter` · DEV.md

- .NET 6,WPF/WinForms 桌面应用
- 窗口透明:Win32 API(SetLayeredWindowAttributes 等)
- 构建:

```bash
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

- 配置:同目录 `WindowTinter.settings.json`

## AE 插件系列(JavaScript / ExtendScript)

> 📌 来源:`AE-Lyrics-Animator`、`AudioScale`、`CircleDiffusion`、`starry-sky-generator` · 各自 DEVELOPMENT.md

共同模式:
- ScriptUI Panel 作为界面
- ExtendScript(ES3 兼容)访问 AE 图层 / 关键帧
- 典型功能:歌词逐字动画、音频驱动缩放、圆形扩散粒子、星空粒子

## C4D / Blender 插件

> 📌 来源:`c4d-mesh-face-sorter`、`blender-mesh-face-sorter`、`blender-car-mesh-optimizer`

- **C4D**:Python 插件(C4D 2023+ 兼容),用户数据(UserData)供 Xpresso 调用
- **Blender**:单文件 .py 插件,零依赖,密度自适应网格优化、面数排序

## 3ds Max(MaxScript)

> 📌 来源:`vray-material-replacer` · DEV.md

- MaxScript 单文件,拖入视口即用,无需安装
- 稳定优先:递归处理多维子材质、嵌套材质,`undo` 包裹
- 导出材质构成 Markdown 供 AI 生成报告
