# M5-09 浏览器扩展踩坑记录

> 📌 本分册条目**摘录自 [knowledge-base](https://github.com/Simiely/knowledge-base)**（经验提炼层），完整条目与细节见对应链接；原始仓库见各条目的 source 字段。

## 权限（最高频）

### MV3 权限三层防线

- **现象**:扩展取不到 Cookie / 权限报错
- **原因**:MV3 的 `cookies` 权限**不含主机权限**,需要分别声明;`getAll` 静默失败
- **解决**:`cookies` + `host_permissions` 双声明,`permissions.contains` 主动检测
- **完整条目**:[MV3扩展权限三层防线.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/MV3扩展权限三层防线.md)

## Service Worker

### SW 注册失败

- **原因**:MV3 Service Worker 注册时机/声明方式不对
- **解决**:顶层同步注册 + 字符串形式 + 无 persistent 字段
- **完整条目**:[MV3ServiceWorker注册规范.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/MV3ServiceWorker注册规范.md)

## 数据与存储

### 重装扩展丢数据

- **现象**:重装/更新后账号数据丢失
- **原因**:扩展 ID 变化导致 storage 隔离
- **解决**:manifest 加 `key` 字段固定扩展 ID
- **完整条目**:[浏览器扩展重装保留数据manifestkey.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/浏览器扩展重装保留数据manifestkey.md)

### Cookie 操作 URL 前导点号

- **现象**:清除 Cookie 有残留
- **原因**:domain 前导点号导致 URL 非法、静默失败
- **解决**:`slice(1)` 去掉前导点号
- **完整条目**:[Cookie操作URL前导点号.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/Cookie操作URL前导点号.md)
