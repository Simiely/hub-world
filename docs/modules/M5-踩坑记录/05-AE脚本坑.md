# M5-05 AE 脚本踩坑记录

> 📌 本分册条目**摘录自 [knowledge-base](https://github.com/Simiely/knowledge-base)**（经验提炼层），完整条目与细节见对应链接；原始仓库见各条目的 source 字段。

## 语法与环境

### ExtendScript ES3 语法红线

- **现象**:AE .jsx 报语法错误或用不了新特性
- **原因**:ExtendScript 引擎仅 ES3——无 `const`/`let`/模板字符串/箭头函数/`class`/**无内置 `JSON` 对象**
- **解决**:用 `function(){}` 匿名函数;JSON 用 polyfill;`node --check 脚本.jsx` 做语法检查
- **完整清单**:[速查表/ES3语法限制速查.md](https://github.com/Simiely/knowledge-base/blob/main/速查表/ES3语法限制速查.md)

### 中文版 matchName 不匹配

- **现象**:`layer.property("Text")` 等在 AE 2026 中文版取不到属性
- **原因**:中文版 matchName/组位置与英文版不同
- **解决**:属性访问用候选 fallback 列表,不硬编码单一 matchName
- **完整条目**:[AE2026中文版matchName兼容.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/AE2026中文版matchName兼容.md)

## ScriptUI 布局

### alignChildren + alignment 双重 fill 宽度失控

- **现象**:面板宽度被撑到 380px 无法控制
- **原因**:`alignChildren="fill"` + 控件 `alignment="fill"` 多重拉伸叠加
- **解决**:fill 用双轴数组形式(如 `["fill","center"]`);面板宽度优先查控件布局而非 preferredSize
- **完整条目**:[ScriptUI布局两坑.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/ScriptUI布局两坑.md)

### visible 切换 / dropdown / 链式赋值

- **现象**:控件 visible 切换不重排、dropdown selection 失效
- **解决**:见 [ScriptUI可见性与控件状态陷阱.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/ScriptUI可见性与控件状态陷阱.md)

## 表达式

### seedRandom 种子管理

- **现象**:批量随机效果错乱、不同属性随机值关联
- **解决**:不同属性用不同 offset(位置 2000/颜色 3000/模糊 10000…),同属性同步用同种子 + timeless
- **完整条目**:[AE表达式seedRandom种子管理.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/AE表达式seedRandom种子管理.md)

### 表达式不用中文名 / 维度继承

- 表达式内不写中文名,用 effect 索引 / matchName + fallback([AE表达式跨语言兼容.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/AE表达式跨语言兼容.md))
- 2D/3D 属性用 `value` 继承维度,别碰 `dimensionsSeparated`([AE表达式维度继承用value关键字.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/AE表达式维度继承用value关键字.md))
