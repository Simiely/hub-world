# M5-04 桌面与脚本工具踩坑记录

> 📌 来源:`WindowTinter` DEV.md、`vray-material-replacer` DEV.md、各 AE/C4D/Blender 插件 DEVELOPMENT.md

## Windows 桌面(C#)

### 管理员权限窗口无法控制

- **现象**:目标窗口以管理员运行,透明效果不生效
- **解决**:本程序也"以管理员身份运行"

### 窗口重新启动后绑定失效

- **现象**:目标窗口关闭再启动,绑定丢失
- **解决**:自动重新绑定机制(记录窗口标识)

## 3ds Max(MaxScript)

### V-Ray 专属参数丢失

- **现象**:替换后反射/折射/光泽度/Fresnel/SSS 没了
- **原因**:Standard/Physical 材质没有对应参数
- **解决**:按"越简单越稳定"原则丢弃;结果保证"能正常打开、无 V-Ray 依赖",不保证渲染效果完全一致

### VRayLightMtl 强度映射不准

- **现象**:极亮自发光灯不够亮
- **原因**:标准自发光没有 HDR 级亮度
- **解决**:颜色对、亮度大致对,接受该限制

### 替换不可逆

- **现象**:替换后想还原 V-Ray
- **解决**:操作包了 `undo`,用 Ctrl+Z 回退

## AE / C4D / Blender 插件

- **AE**:ExtendScript 是 ES3,不能用现代 JS 语法(详见各插件 DEVELOPMENT.md)
- **C4D**:不同版本 API 差异大,目标 C4D 2023+,兼容 2024/2025/2026
- **Blender**:单文件插件零依赖,避免安装第三方库
