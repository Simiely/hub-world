# M5-01 微信小程序踩坑记录

> 📌 来源:`potty-training-miniprogram` DEV.md(最全,历史问题库)、`collab-plan-miniprogram` docs/09-pitfalls.md(51 条)、`miniprogram-item-expiry` DEVELOPMENT.md

## 布局与适配

### iPad / 大屏适配(CSS @media 失效)

- **现象**:iPad 上小程序 CSS `@media` 查询不命中;`windowWidth` 返回的是手机比例绘制区宽度
- **原因**:小程序在 iPad 上以真实逻辑尺寸运行,媒体查询与窗口 API 行为与浏览器不同
- **解决**:`app.json` 启用 `"resizable": true`;用 `screenWidth`(物理屏宽,iPad 横屏≈1366/竖屏≈1024)判定平板;挂 `.tablet` 类;平板样式全部用 `.tablet` 后代选择器 + **px** 覆盖

## 云开发 / 云函数

### 云函数共享代码不同步

- **现象**:改了 `_shared` 公共代码,部署云函数后行为没变
- **原因**:云函数各自独立打包,公共代码需要手动同步
- **解决**:`npm run sync:shared` 同步到各云函数 `common/`

### 腾讯文档 OAuth 回调需要备案域名

- **现象**:OAuth 授权回调失败
- **原因**:腾讯文档开放平台要求 `redirect_uri` 是**自己备案的域名**
- **解决**:准备备案域名;云开发调用本身免白名单,只有 OAuth 需要

### 云库与外部系统双向同步

- **现象**:重复同步 / 删除找不到对应记录
- **原因**:缺少云库 `_id` 与外部 `recordId` 的映射
- **解决**:建 `mapping` 集合存映射,防重复、供删除定位;反向同步用时间戳水位线只拉变化记录

## 其他

### 生物认证兼容

- **现象**:指纹/面容在部分设备(如鸿蒙)不可用
- **解决**:平台检测 + 降级到密码验证,密码错误红点抖动提示
