# M5-06 C4D 插件踩坑记录

> 📌 本分册条目**摘录自 [knowledge-base](https://github.com/Simiely/knowledge-base)**（经验提炼层），完整条目与细节见对应链接；原始仓库见各条目的 source 字段。

## C4D 2026 SDK 迁移（最高频）

### 移除的 API 与 positional-only 变化

- **现象**:老插件在 C4D 2026 加载报 AttributeError / TypeError
- **原因**:2026 新版 SDK 移除一批 UI API(ListView/GePopupMenu/ScrollGroupEnd/gui.Question),且 `AddStaticText border=`、`AddComboBox cols=` 等 kwargs 变为**仅位置参数**
- **解决**:完整迁移清单见 [C4D2026SDK破坏性迁移清单.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/C4D2026SDK破坏性迁移清单.md);遇代码未生效先清 `.pypc` 缓存
- **其他**:参数命名坑(`GroupBegin title=`、ScrollGroupEnd 不存在)见 [C4DPythonSDK参数命名坑.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/C4DPythonSDK参数命名坑.md)

## 对话框与生命周期

### 二次打开崩溃 / 面板空白

- **现象**:对话框二次打开崩溃、面板空白
- **原因**:对话框对象被 GC 回收、RestoreLayout 二次调用
- **解决**:`self._dlg` 保持引用 + RestoreLayout 直接返回
- **完整条目**:[C4D对话框生命周期与二次打开崩溃.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/C4D对话框生命周期与二次打开崩溃.md)

### 隐藏/显示不生效

- **原因**:可见性控制 API 选择不当、快照只在第一次保存
- **解决**:`SetEditorMode` 最可靠;见 [C4D可见性控制与状态快照.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/C4D可见性控制与状态快照.md)

## 数据与对象

### 对象识别用 GUID

- **现象**:按名称查找/选中对象错乱
- **原因**:对象名称不唯一(重名)
- **解决**:用 `GetGUID()` 标识对象;见 [C4D对象用GUID标识.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/C4D对象用GUID标识.md)

### 用户数据写入类型与单位

- **现象**:用户数据默认值异常
- **解决**:`DESC_DEFAULT` 类型匹配、PERCENT 用 0-1、不写 0;见 [C4D用户数据写入类型与单位.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/C4D用户数据写入类型与单位.md)

### 动态多列列表

- **解决**:ScrollGroup + 每行独立 Group 模拟 ListView;见 [C4D动态列表控件方案.md](https://github.com/Simiely/knowledge-base/blob/main/解决方案/C4D动态列表控件方案.md)
